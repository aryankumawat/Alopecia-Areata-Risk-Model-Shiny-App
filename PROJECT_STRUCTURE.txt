API ENDPOINTS
=============

POST /api/predict
  - Individual risk prediction
  - Input: JSON with demographics + genes
  - Output: Prediction, probability, risk level

POST /api/batch-predict
  - Batch risk prediction
  - Input: CSV file
  - Output: Array of predictions

GET /api/genes
  - Get gene list and symbols
  - Output: Gene IDs and mappings

QUICK START
===========

1. Install dependencies:
   $ npm install

2. Start the server:
   $ npm start
   
   Or use the startup script:
   $ ./start.sh

3. Open browser:
   http://localhost:3000
